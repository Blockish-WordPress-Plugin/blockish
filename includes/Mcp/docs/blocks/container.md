### `blockish/container`

The primary layout block — flexbox or CSS grid. **Accepts children: yes.**

> [!WARNING]
> **Common Mistake:** After designing your container, ALWAYS double-check your `flexDirection`, `alignItems`, and `justifyContent` settings. These are frequently misconfigured.

### Markup & CSS Generation

**Frontend Markup Structure (from `save.js`):**
```jsx
<>
			<Tag {...innerBlockProps}>
				{backgroundVideo?.url && (
					<video
						className="blockish-container-background-video"
						src={backgroundVideo.url}
						autoPlay
						muted
						loop
						playsInline
						aria-hidden="true"
					/>
				)}
				{innerBlockProps.children}
			</Tag>
		</>
```
*Note: The actual HTML tag might be dynamic (e.g., `div`, `section`). A unique class `bb-[hash]` and `blockish-block-wrapper` are automatically injected server-side.*

**CSS Generation & Injection:**
Dynamic CSS is generated by `includes/Core/StyleGenerator.php` and injected in the `<head>` or footer as inline styles.

**CSS Mapping per Attribute:**
- `overflow`: Maps to:
  - `.{{WRAPPER}}.blockish-container` -> `overflow: {{VALUE}};`
- `customWidthContainer`: Maps to:
  - `.{{WRAPPER}}.align-custom-width` -> `max-width: {{VALUE}};`
- `containerMinHeight`: Maps to:
  - `.{{WRAPPER}}` -> `min-height: {{VALUE}};`
  - `.{{WRAPPER}} > .block-list-appender` -> `min-height: {{VALUE}};`
- `display`: Maps to:
  - `.{{WRAPPER}}.blockish-container` -> `display: {{VALUE}};`
- `flexWrap`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-flex` -> `flex-wrap: {{VALUE}};`
- `flexDirection`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-flex` -> `flex-direction: {{VALUE}};`
- `justifyContent`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-flex` -> `justify-content: {{VALUE}};`
- `alignItems`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-flex` -> `align-items: {{VALUE}};`
- `autoGridWidth`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-grid.grid-layout-type-auto` -> `grid-template-columns: repeat(auto-fill,minmax(min({{VALUE}},100%),1fr));`
- `autoGridHeight`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-grid.grid-layout-type-auto` -> `grid-auto-rows: minmax({{VALUE}}, auto);`
- `gridColumns`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-grid.grid-layout-type-fixed` -> `grid-template-columns: repeat({{VALUE}}, minmax(0, 1fr));`
- `gridRows`: Maps to:
  - `.{{WRAPPER}}.blockish-container.layout-type-grid.grid-layout-type-fixed` -> `grid-template-rows: repeat({{VALUE}}, minmax(0, 1fr));`
- `columnGap`: Maps to:
  - `.{{WRAPPER}}.blockish-container` -> `column-gap: {{VALUE}};`
- `rowGap`: Maps to:
  - `.{{WRAPPER}}.blockish-container` -> `row-gap: {{VALUE}};`
- `containerBackground`: Uses `BlockishBackground` on `.{{WRAPPER}}`
- `containerHoverBackground`: Uses `BlockishBackground` on `.{{WRAPPER}}:hover`
- `containerBackgroundOverlay`: Uses `BlockishBackgroundOverlay` on `.{{WRAPPER}}.has-background-overlay::before`
- `containerHoverBackgroundOverlay`: Uses `BlockishBackgroundOverlay` on `.{{WRAPPER}}.has-background-overlay::before:hover`
- `containerBorder`: Uses `BlockishBorder` on `.{{WRAPPER}}`
- `containerHoverBorder`: Uses `BlockishBorder` on `.{{WRAPPER}}:hover`
- `containerBorderRadius`: Maps to:
  - `.{{WRAPPER}}` -> `border-radius: {{TOP_LEFT}} {{TOP_RIGHT}} {{BOTTOM_RIGHT}} {{BOTTOM_LEFT}};`
- `containerHoverBorderRadius`: Maps to:
  - `.{{WRAPPER}}:hover` -> `border-radius: {{TOP_LEFT}} {{TOP_RIGHT}} {{BOTTOM_RIGHT}} {{BOTTOM_LEFT}};`
- `containerBoxShadow`: Uses `BlockishBoxShadow` on `.{{WRAPPER}}`
- `containerHoverBoxShadow`: Uses `BlockishBoxShadow` on `.{{WRAPPER}}:hover`
